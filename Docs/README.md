Esta carpeta conserva documentación de la versión original del proyecto NEXUS.

## Manual disponible

- Manual Técnico y Guía de Estudio NEXUS.pdf

El manual describe principalmente el funcionamiento de la versión de consola y sus clases desarrolladas en C#.

## Documentación actual

La documentación actualizada de NEXUS V2.0 se encuentra en la carpeta `docs/` (minúscula).

Allí se incluyen el diseño del juego, la arquitectura actual y propuesta, el modelo de datos, el análisis técnico y las evidencias visuales.
